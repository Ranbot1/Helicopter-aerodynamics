# 直升机空气动力学 · 学习笔记

> 以《直升机空气动力学》（招启军、徐国华、王博 著，工业和信息化部"十四五"规划教材）为主线整理的**个人学习笔记**：把每一章拆成"概念 → 结论 → 逻辑关系 → 自测"几步，配公式推导和思维导图，便于复习与查阅。

## 这本书讲什么

直升机与固定翼最本质的差别在于：**升力、牵引力与操纵力全部来自旋翼**。由此带来两件事——旋翼气动是全机气动问题的基础；而旋翼又同时处在旋转、挥舞、摆振、变距的复合运动之中，流场远比固定翼复杂。全书 12 章正是围绕"如何描述并计算这套复杂的气动力"展开：

- **第一篇 基础**（第 1–2 章）：直升机是什么、怎么发展来的、旋翼靠什么工作。
- **第二篇 经典理论**（第 3–6 章）：滑流（动量）理论 → 叶素理论 → 涡流理论，三条逐层深入的解析路线。
- **第三篇 现代方法与专项问题**（第 7–10 章）：CFD 方法、气动噪声、飞行性能、特殊飞行状态。
- **第四篇 设计与试验**（第 11–12 章）：气动外形设计准则与相似准则下的试验方法。
