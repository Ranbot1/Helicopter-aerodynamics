## 4.1 引言

和固定翼飞机的机翼一样，直升机旋翼的桨叶也是由翼型一节一节"串"起来的，翼型的几何形状是旋翼最基本的几何特征之一。旋翼翼型的气动特性直接决定桨叶乃至整机的气动性能，在直升机空气动力学理论与设计中地位极重——毫不夸张地说，旋翼设计前必须做的一项工作，就是旋翼翼型的选择与设计。

本章先介绍翼型的基本参数与理论，再据此突出旋翼翼型的特殊性，最后给出几类旋翼专用翼型。学习时建议同步拓展阅读其他空气动力学教材的对应内容，并始终带着一个问题：旋翼对翼型气动特性到底有什么特殊要求？

## 4.2 翼型基本参数

要分析翼型，第一步得先把它"量化"。这一节解决的是：**如何用几个无量纲的几何量，唯一地描述一片翼型的形状**。

#### 4.2.1 几何弦长

翼型最尖的那一点称为**后缘**（trailing edge）；在翼型轮廓线的所有点里，离后缘距离最远的那一点称为**前缘**（leading edge）。连接前缘与后缘的线段叫**弦线**（chord line），其长度就是**几何弦长**，简称**弦长**，用 $c$ 表示。弦长是翼型的特征尺寸（图 4.1，原书插图）。

#### 4.2.2 翼型无量纲坐标

为方便使用，通常对翼型外形做无量纲处理：取弦长 $c$ 为参考长度，坐标原点放在前缘，$x$ 轴沿弦线指向后缘，$y$ 轴向上。无量纲后翼型弦长为 1，上表面（upper surface）与下表面（lower surface）的纵坐标分别写成：

$$\bar{y}_u(x)=\frac{y_u}{c}=f_u(x), \qquad \bar{y}_l(x)=\frac{y_l}{c}=f_l(x)$$

式中的 $\bar{y}_u=f_u(x)$、$\bar{y}_l=f_l(x)$ 既可以用数学解析式表达，也可以由数据表给出。

#### 4.2.3 厚度（thickness）

翼面到中弧线的 $y$ 方向无量纲距离，称为**厚度分布函数** $\eta(x)$；其最大值的 2 倍称为**相对厚度** $t$，所在弦向位置记为 $x_t$。即：

$$\eta(x)=\frac{1}{2}\big[\bar{y}_u(x)-\bar{y}_l(x)\big]$$

$$t = \frac{t_{\max}}{c}=2\,\eta_{\max}, \qquad x_t \text{ 为 } \eta(x) \text{ 取最大值处}$$

直观理解：厚度分布函数就是"半厚度"。相对厚度 $t$ 通常写成百分数，例如 $t=12\%$ 表示翼型最厚处是弦长的 12%。一般把相对厚度约 $12\%$ 及以下的翼型称为**薄翼型**。

#### 4.2.4 弯度（camber）

翼型上、下表面平行于 $y$ 轴连线的中点连成的曲线，称为**中弧线**（mean line / camber line），它描述翼型的弯曲特征。中弧线的无量纲纵坐标 $f(x)$ 称为**弯度分布函数**，其最大值称为**相对弯度** $f$，所在弦向位置记为 $x_f$：

$$f(x)=\frac{1}{2}\big[\bar{y}_u(x)+\bar{y}_l(x)\big]$$

$$f=\frac{f_{\max}}{c}, \qquad x_f \text{ 为 } f(x) \text{ 取最大值处}$$

一个关键判断：**若中弧线是一条直线，则上、下表面必然关于弦线对称，这种翼型就是对称翼型（symmetric airfoil）**。对称翼型没有弯度（$f=0$），其零升迎角为 $0^\circ$；而有弯度的翼型，零升迎角通常为负。

## 4.3 翼型空气动力与力矩

翼型的气动载荷包括压强分布、剪切应力分布、升力、阻力与俯仰力矩等。所谓"气动特性"，就是这些载荷随各种因素变化的规律。影响因素可归为三类：几何参数（厚度、弯度等）、翼型与气流的相对运动（迎角、来流速度）、流体属性（黏性、惯性、压缩性）。

#### 4.3.1 气动力的两个来源

从本质上讲，翼型的空气动力与力矩只来源于两点：

1. **压力 $p$ 的分布**；
2. **剪切应力 $\tau$ 的分布**。

无论翼型外形多么复杂，其气动力终究都是表面上的压力与剪切应力积分的结果。对翼型上任一个微元表面，压力沿表面法向、剪切应力沿表面切向，如图 4.2 所示。

<img src="assets/ch4/fig4-2.png" alt="图 4.2 翼型的压力与剪切应力示意图" loading="lazy">

对整个翼型表面的压力与剪切应力积分，就得到合成气动力 $F$ 和绕某参考点的力矩 $M$，如图 4.3（原书插图）。

#### 4.3.2 气动力与力矩的分解

气动力 $F$ 可以沿两套坐标系分解：

- 沿**来流方向**分解，得到**升力** $F_L$ 与**阻力** $F_D$；
- 沿**弦线方向**分解，得到**法向力** $F_N$ 与**切向力** $F_A$。

二者的关系由迎角 $\alpha$（攻角，angle of attack）联系。当来流与弦线夹角为 $\alpha$ 时（图 4.4，原书插图）：

$$F_L = F_N\cos\alpha - F_A\sin\alpha$$

$$F_D = F_N\sin\alpha + F_A\cos\alpha$$

如果已知翼型表面压强与剪切应力分布（图 4.5），就可以通过沿表面积分求出法向力、切向力与绕前缘的力矩。图 4.5 给出了表面压力系数与剪切应力的分布示意，工程上常据此近似确定升力和力矩特性。

<img src="assets/ch4/fig4-5.jpg" alt="图 4.5 翼型的表面压力与剪切应力示意图" loading="lazy">

#### 4.3.3 无量纲气动系数

有量纲的力、力矩不便比较，工程上改用无量纲系数：取自由来流速度 $V_\infty$、空气密度 $\rho$、弦长 $c$ 为参考量，定义

$$C_L = \frac{F_L}{\frac{1}{2}\rho V_\infty^2 c}, \qquad C_D = \frac{F_D}{\frac{1}{2}\rho V_\infty^2 c}$$

$$C_M = \frac{M}{\frac{1}{2}\rho V_\infty^2 c^2}, \qquad C_p = \frac{p-p_\infty}{\frac{1}{2}\rho V_\infty^2}$$

其中 $C_L$、$C_D$、$C_M$、$C_p$ 分别为升力系数、阻力系数、俯仰力矩系数与压力系数。小迎角时，若已知压强系数分布 $C_p(x)$，升力系数与力矩系数可由下列积分求得：

$$C_L = \int_0^1 \big(C_{p,l}-C_{p,u}\big)\,dx$$

$$C_M = -\int_0^1 \big(C_{p,l}-C_{p,u}\big)\,x\,dx$$

式中下标 $u$、$l$ 分别指上、下表面。NACA 0012 等常见翼型的压强分布有系统的风洞数据，可从翼型手册查得。

#### 4.3.4 压力中心与气动中心

翼型上有两个重要气动特征点（图 4.6，原书插图）：**压力中心**（center of pressure）与**气动中心**（aerodynamic center，又称焦点）。

- **压力中心** $O_{cp}$：气动合力（或其法向分量 $F_N$、切向分量 $F_A$）的作用线与弦线的交点，绕该点的气动力矩为零。它到前缘的距离记为 $x_{cp}$，由绕前缘力矩 $M_{LE}$ 与法向力确定：

$$x_{cp} = -\frac{M_{LE}}{F_N} = -\frac{C_M}{C_N}\,c$$

- **气动中心** $O_{ac}$：使绕该点的力矩系数不随迎角（不随法向力系数 $C_N$）变化的那个固定点。对任意距前缘为 $x$ 的点，绕其力矩系数为

$$C_{M,x} = C_M + x\,C_N = C_{M0} + \left(\frac{\partial C_M}{\partial C_N}+x\right)C_N$$

令 $x = x_{ac} = -\dfrac{\partial C_M}{\partial C_N}$，则 $C_{M,x}=C_{M0}$ 为常数——这就是气动中心的定义。翼型绕气动中心的力矩系数始终等于**零升力矩系数** $C_{M0}$，且气动中心位置固定、不随迎角移动。因此气动中心可理解为"迎角变化引起的升力增量的作用点"。

绕前缘力矩系数与气动中心的关系：

$$C_M = C_{M0} - x_{ac}\,C_N$$

压力中心与气动中心的关系则为：

$$x_{cp} = x_{ac} - \frac{C_{M0}}{C_N}$$

由此可得两条实用结论：

1. **对称翼型** $C_{M0}=0$，压力中心与气动中心重合；**非对称翼型**二者不重合。旋翼翼型一般 $C_{M0}<0$，迎角增大时压力中心前移；$C_N>0$ 时压力中心位于气动中心之后。
2. 桨叶设计中最好让**变距轴通过翼型气动中心**，这样飞行状态变化不会改变桨叶上的俯仰力矩系数，旋翼操纵机构载荷变化更小，驾驶员负担更轻。

## 4.4 翼型静态气动特性

通过风洞试验，通常能得到三条基本曲线：升力特性 $C_L=f(\alpha)$、阻力特性 $C_D=f(\alpha)$、力矩特性 $C_M=f(\alpha)$。下面分四条线索展开。

#### 4.4.1 升力特性

升力特性用升力曲线 $C_L$–$\alpha$ 表示（图 4.7(a)）。中低迎角下 $C_L$ 与 $\alpha$ 近似线性，这段斜率记为 $a_\infty$，叫**升力线斜率**；此范围内气流平稳贴附在翼型表面。

迎角继续增大，上表面气流逐渐分离，分离区出现与自由流反向的"反向流"，这就是**失速**的先兆。失速前升力达到极值，称为**最大升力系数** $C_{L\max}$，对应迎角叫**临界迎角**（失速迎角）$\alpha_{ss}$（下标 ss 表示静态失速 static stall）。$C_{L\max}$ 是判断翼型性能优劣的关键指标。

再看曲线另一端：升力为 0 对应的迎角是负的，叫**零升迎角** $\alpha_0$。正弯度翼型 $\alpha_0$ 通常在一 $3^\circ$ 至 $-2^\circ$ 之间；对称翼型的零升迎角为 $0^\circ$。

#### 4.4.2 力矩特性

力矩特性用力矩曲线 $C_M$–$\alpha$ 表示（图 4.7(b)）。它也常用 $C_M$–$C_L$ 或 $C_{M1/4}$–$C_L$ 表示，关系为：

$$C_M = C_{M0} + \frac{\partial C_M}{\partial C_L}\,C_L$$

其中 $\partial C_M/\partial C_L$ 一般为负，意味着升力越大、低头力矩越大。理论与试验均表明：迎角不太大时 $C_M$–$C_L$ 近似直线，迎角较大时该曲线出现弯曲。

力矩特性对旋翼操纵影响很大。由于旋翼靠总距与周期变距操纵，操纵机构要克服气流作用在桨叶上的**铰链力矩**。为降低操纵载荷、减轻驾驶员负担，旋翼翼型选型时通常要求典型状态下绕 1/4 弦线的力矩系数 $|C_{M1/4}|<0.01$。本书若无特别说明，将 $C_{M1/4}$ 简写为 $C_M$。

#### 4.4.3 阻力特性与极曲线

阻力特性用阻力曲线 $C_D$–$\alpha$ 表示（图 4.8(a)，原书插图）。低速时阻力由黏性引起，分为两部分：翼面剪切应力造成的**摩擦阻力**，以及边界层改变位流压强分布造成的**压差阻力**。小迎角时摩擦阻力为主；迎角或升力系数增大，边界层增厚、尾迹加宽，压差阻力渐占主导；一旦失速，压差阻力迅速增大。

设计中更常用 **$C_L$–$C_D$ 曲线（极曲线）** 表示升阻特性（图 4.8(b)，原书插图）。极曲线上每一点对应一个迎角，原点到该点的连线表示此迎角下气动合力的大小与方向——极曲线本质上是空气动力合力的矢量曲线。从极曲线可找到五个特征点：

1. **最小阻力系数** $C_{D\min}$；
2. **最有利状态点**：升阻比 $(C_L/C_D)_{\max}$ 最大，对应航程最远；
3. **最经济状态点**：$(C_L^{1/2}/C_D)_{\max}$ 最大，对应续航时间最长；
4. **最大升力系数点** $C_{L\max}$；
5. **零升阻力系数** $C_{D0}$：升力为 0 时的阻力系数，通常接近 $C_{D\min}$。

#### 4.4.4 雷诺数与马赫数的影响

**雷诺数** $Re$ 体现黏性的影响，定义为：

$$Re = \frac{\rho V L}{\mu}$$

对翼型流动，取来流速度 $V_\infty$ 与弦长 $c$ 为特征速度与特征长度，即 $Re=\rho V_\infty c/\mu$。雷诺数对升力线斜率影响甚微，却显著影响最大升力系数：雷诺数增大→黏性影响减小→气流分离推迟→$C_{L\max}$ 增大。常用低速翼型 $C_{L\max}\approx 1.3\sim 1.7$。雷诺数与表面光洁度还决定附面层状态与转捩点位置，一般型阻随雷诺数增大而减小（图 4.9，原书插图）。

**马赫数** $Ma$ 体现压缩性影响，一般认为 $Ma>0.3$ 后特性受压缩性明显影响（图 4.10，原书插图）。马赫数主要带来两方面变化：

1. 升力线斜率随马赫数增大而增大，即著名的**普朗特–格劳特效应**（Prandtl–Glauert）；
2. 最大升力系数、失速迎角与力矩发散迎角随马赫数增大而减小——因为分离在更小迎角下就发生了；小马赫数时分离由高逆压梯度引起，大马赫数时由激波引起。

对旋翼而言，前行侧桨尖常处于**高马赫数、低升力**状态，所以高马赫数下的阻力特性直接关系到旋翼功率消耗。当马赫数超过某临界值，阻力快速增加，该临界值称为**阻力发散马赫数** $Ma_{DD}$；其中升力系数 $C_L=0$ 时的阻力发散马赫数叫**零升阻力发散马赫数** $Ma_{DDO}$，通常定义为 $\dfrac{dC_D}{dMa}=0.1$ 处的马赫数。相对厚度与相对弯度增大都会使 $Ma_{DD}$ 减小。

## 4.5 翼型动态气动特性

旋翼桨叶在旋转，即使定常前飞，前行侧来流大、后行侧来流小；为平衡气动力，桨叶还做变距、挥舞等耦合运动，使剖面迎角随方位角剧烈变化。高桨盘载荷时，后行桨叶大迎角下的气流分离与失速以更"动态"的方式随时间演变，这就是**动态失速**（dynamic stall）。它会增大升力峰值，但同时造成阻力与力矩突增、气动中心不再稳定，严重影响旋翼振动特性，制约气动性能与飞行速度提高。

按 McCroskey 的定义：任何翼型或升力面做随时间变化的俯仰、急降等非定常运动，使有效迎角超过静态失速迎角时，即发生动态失速。它与静态失速的关键区别在于：气流分离被**推迟**到比定常状态更高的迎角，分离表现为**动态失速涡**的脱离；涡附着在翼型上表面时还能持续提供升力。

#### 动态失速过程与缩减频率

研究时常假设翼型绕 1/4 弦线做一阶简谐振荡，迎角变化为：

$$\alpha = \alpha_0 + \alpha_m\sin(\omega t) = \alpha_0 + \alpha_m\sin(2\pi f t)$$

其中 $\alpha_0$、$\alpha_m$ 为迎角平均值与振幅，$\omega$、$f$ 为振荡角频率与频率。衡量非定常程度的无量纲参数是**缩减频率**（减缩频率）$k$：

$$k = \frac{\omega c}{2V_\infty}$$

按 $k$ 值可粗分流动类型：$k=0$ 为定常；$0<k\le 0.05$ 为准定常；$k>0.05$ 为非定常，其中 $k>0.2$ 时非定常特性很强。

#### 动态失速的五个阶段

以 NACA 0012 翼型的迟滞回线试验（图 4.11–4.13，原书插图）为例，动态失速通常分五阶段：

1. **迟滞段**：迎角超过静态失速迎角，气流仍附着，升力系数持续增加；
2. **涡生成段**：前缘形成动态失速涡并沿表面输运，带来额外升力使 $C_{L\max}$ 远超静态值，同时阻力迅速增加；涡引起压力中心后移，涡流过 1/4 弦线后低头力矩逐渐增大——阻力与力矩发散都发生在涡生成输运初期；
3. **涡脱落段**：涡能量降低、从表面脱落进入尾迹，升力系数骤降、表面完全分离，阻力与低头力矩达峰值后回落；
4. **迎角回落段**：迎角从最大减小，大范围分离仍持续，各系数随之减小；
5. **再附着段**：局部气流再附着，伴明显迟滞，直到迎角足够小才完全附着。

从力矩系数迟滞回线看，$C_M$ 也呈迟滞回线：逆时针回线所围面积为正，气动力矩做负功，即该阶段有**正阻尼**使振动衰减；顺时针回线所围面积为负，气动力矩做正功，该阶段有**负阻尼**使振动扩散。若两面积代数和为正，迎角振荡便有负气动阻尼，可能引发自激振动——**桨叶失速颤振**。

## 4.6 旋翼专用翼型

直升机在悬停、前飞、机动等状态下，旋翼面临宽马赫数、宽迎角、宽雷诺数范围的气动环境；与固定翼不同，旋翼翼型还必须在严重非定常环境下工作，尤其前飞与机动状态。因此翼型需在很宽的工作范围内都保持良好特性。美、俄、法、英等把旋翼翼型设计视为核心技术之一。早期直升机多用 NACA 系列翼型，20 世纪 70 年代后逐步转向旋翼专用翼型。

典型谱系有：俄罗斯中央流体动力学研究院（TsAGI）的 TsAGI 系列（已发展到 TsAGI-5）、法国 ONERA 的 OA 系列（已到 OA5）、美国波音的 VR 系列、西科斯基的 SC 系列等（图 4.14、图 4.15）。

一个核心判断：**旋翼不能直接借用固定翼翼型**，因为固定翼翼型主要按定常、对称、单工况优化，而旋翼翼型要在旋转带来的强非定常、宽迎角与跨声速环境下兼顾升力、阻力发散与力矩特性。

## 本章小结

1. **几何描述**是地基：用几何弦长 $c$ 做无量纲化，再用厚度分布 $\eta(x)$、弯度分布 $f(x)$ 两个函数唯一确定翼型形状；中弧线为直线即对称翼型。
2. **气动力**只来源于表面压力与剪切应力，积分后得到合力 $F$ 与力矩 $M$；沿来流分解为升力/阻力，沿弦线分解为法向力/切向力，二者由迎角 $\alpha$ 联系。
3. **无量纲系数**（$C_L,C_D,C_M,C_p$）便于比较；小迎角下升力与力矩可由压强系数积分直接求出。
4. **两个特征点**：压力中心是合力作用线交点、随迎角移动；气动中心是力矩系数不随迎角变的点、位置固定。对称翼型二者重合，非对称翼型不重合。
5. **静态特性**用三条曲线加一张极曲线表达；极曲线上可读取最小阻力、最有利、最经济、最大升力、零升阻力五个特征点。
6. **两大相似参数**：雷诺数主导黏性与分离（影响 $C_{L\max}$），马赫数主导压缩性（普朗特–格劳特效应抬高斜率，却压低 $C_{L\max}$ 与失速迎角，并引入阻力发散马赫数）。
7. **动态失速**是旋翼特有的非定常失速，靠动态失速涡推迟分离、增大峰值升力，却带来阻力/力矩突增与负气动阻尼风险（失速颤振），分五阶段演化。
8. **旋翼专用翼型**因强非定常、宽工况环境而不可直接借用固定翼翼型，发展出谱系化（TsAGI）与定制专用化（OA）两条路线。
